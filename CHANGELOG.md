# Novità di Nod

Una sezione per versione, la più recente in alto. L'app mostra queste righe dopo ogni aggiornamento (Sources/Changelog.swift):
titolo `## <versione> · <data>`, poi una riga `- ` per novità, scritta per chi usa l'app.

## 0.1.0 · 2026-10-11
- Prima versione: configurazione guidata con prova di AirPods, Apple Watch e notifiche.
- Presenza: quando ti allontani il Watch ti chiede se tenere sveglio il Mac; senza risposta decide la tua regola (app aperta, giorni, fascia oraria).
- Approvazioni: prova del flusso completo, annuisci e conferma sul Watch, scuoti per negare.
- Notifiche tramite ntfy.sh o un server tuo.
