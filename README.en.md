# Nod

Hands-free approvals and presence for [Cocaine](https://github.com/Mattiakart/cocaine), with AirPods and Apple Watch.
An independent project, not affiliated with Cocaine. [Italiano](README.md)

## Main features

- **Hands-free approvals, even away from the Mac**: nod with your AirPods; from the Watch, answer Approve or Deny in the
  ntfy notification, or approve by completing the reminder. **Coming**: real AI requests will arrive when Cocaine adds the
  channel for companion apps; today you try them with *Try an approval*.
- **Presence**: when you walk away the Watch asks whether to keep the Mac awake; with no answer, your rule decides.
- **Languages**: Italian, English, French, Spanish (Settings > Appearance > Language).
- **Updates**: automatic check, what's new in the new version and a ready-made command (also "Update in Terminal").
- **Watch alerts**: an ntfy notification with buttons and, if you like, a native Reminders alert (iCloud), with no app to install.
- **Diagnostics**: an automatic report with no secrets, to save and attach to a report.

## Known issues

- **Watch side-button double-click: experimental.** On macOS 27 the system closes the request but answers "cancelled" to
  every app, Apple's included. It is a macOS/watchOS defect and we are waiting for a fix from Apple. Meanwhile answer from
  the Watch with the ntfy notification (Approve or Deny) or approve by completing the reminder. The double-click stays in
  Diagnostics, to try it again after an update.
- **The reminder can only approve.** To deny, use the ntfy notification, or let the request expire: nothing happens.

## Requirements

macOS 14 Sonoma or later, AirPods with motion sensors (AirPods Pro, AirPods 3 and 4, AirPods Max; optional), Apple Watch
with an iPhone for notifications. Nod has been tested on macOS 27: it should work on earlier versions, but if you run into
problems, please report them.

## Installation (for users)

```
brew trust gguidotz/tap
brew install --cask gguidotz/tap/nod
```

Homebrew downloads the DMG from the release, copies Nod into Applications and removes the quarantine (the app is not
notarized), so no "Open anyway". The guided setup opens on first launch. Update: `brew upgrade --cask nod` (after the
update Nod shows what's new). Uninstall: `brew uninstall --cask nod` (`--zap` also deletes preferences).

## Building (for developers)

You need macOS 14+ and the command line tools (`xcode-select --install`); no Xcode project, like Cocaine.

```
./make-signing-identity.sh   # once: a stable signature, so macOS doesn't forget permissions on every build
./build.sh --install         # builds, signs, copies to /Applications and opens
```

With Xcode installed, `build.sh` also builds the Liquid Glass icon (`Resources/Icon/Nod.icon`, Icon Composer format) and
checks it by drawing it like the Dock (`tools/icon-check`): if it comes out empty it uses the classic icon
(`Resources/Icon/AppIcon-1024.png`, generated by `tools/render-icon.py`) and leaves previews in `build/icon-preview.png`
and `build/icon-actool.png`. Without Xcode, classic icon.

## If the Watch doesn't receive the request

Diagnostics > *Test the Watch via osascript* makes the same request from an Apple-signed process. From Terminal:

```
xcrun swift tools/watch-probe.swift          # Watch only
xcrun swift tools/watch-probe.swift both     # Touch ID or Watch
```

If the Watch receives it this way and not from Nod, the limit is Nod's local signature. If it doesn't receive it even so,
it is the known macOS 27 problem described above.

## Releasing a version

Once:

1. The repos already exist: **`GGuidotz/nod`** (code and releases with DMGs) and **`GGuidotz/homebrew-tap`** (the cask; the
   name must start with `homebrew-`: that is how `gguidotz/tap/nod` finds it).
2. Clone the tap: `git clone https://github.com/GGuidotz/homebrew-tap ~/Developer/homebrew-tap` (or set `NOD_TAP_DIR`).
3. `brew install gh && gh auth login`.

For each version:

1. Raise `VERSION` and add at the top of `CHANGELOG.md` the section `## <version> · <date>` (in English, with
   `### New Features`, `### Improvements`, `### Bug Fixes`, `### Known Issues`). Translations: `python3 tools/translations.py`
   and `tools/check-strings.py`.
2. Commit, then `./release.sh`: it builds the signed DMG, the `v<version>` release with the DMG and the changelog notes,
   updates `version` and `sha256` of the cask and publishes it to the tap.

It is the same scheme as Cocaine (`mattiakart/tap/cocaine`): a GitHub release with the DMG, a cask in the tap pointing at
the release, quarantine removed at install.

## Structure

| File | What it does |
|---|---|
| `Sources/NodApp.swift` | Scenes: window, Settings, menu bar icon, commands |
| `Sources/AppModel.swift` | App state, when to show setup and what's new |
| `Sources/Setup.swift` | Guided setup; `introducedIn` shows only the new steps after an update |
| `Sources/Changelog.swift` | What's new, read from the `CHANGELOG.md` bundled in the app |
| `Sources/PresenceEngine.swift` | Leaving / away / at the Mac, Watch prompt, no-answer rule |
| `Sources/Preferences.swift` | Preferences and the presence rule (apps, days, time window) |
| `Sources/NotificationRelay.swift` | ntfy: notifications with buttons, single-use tokens, listening for answers |
| `Sources/ReminderRelay.swift` | Reminders alerts (iCloud list "Nod"), deleted after the answer |
| `Sources/HeadMotion.swift` | AirPods: worn, attitude, nod/shake, walking |
| `Sources/WatchConfirm.swift` | Confirmation with the Watch side button (policy chain, osascript probe) |
| `Sources/IconHealth.swift`, `IconMetrics.swift` | Dock icon check at launch and in `build.sh` (`tools/icon-check`) |
| `Sources/ApprovalFlow.swift` | Flow of one approval (currently being tried) |
| `Sources/CocaineBridge.swift` | Cocaine through its command line |
| `packaging/homebrew/Casks/nod.rb` | The cask for the tap |
| `Sources/Diagnostics.swift`, `DiagnosticsView.swift` | Event log and diagnostics report |
| `Sources/Updater.swift`, `UpdatesView.swift` | Update check and update command |
| `Sources/Localization.swift`, `Localization/` | Languages (`L("…")`), translations generated by `tools/translations.py` |
